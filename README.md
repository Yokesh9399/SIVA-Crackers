# SIVA Crackers – Product Catalogue & Business Management Platform

Informational product catalogue and (later) shop management system for **SIVA Crackers**, a family-owned crackers retail shop in Eachanari, Coimbatore, Tamil Nadu.

> **Legal notice:** the public website is an information catalogue only. It does not sell, book, accept payment for, or deliver firecrackers online. All purchases happen in person at the shop.

> **Demo data:** products, brands, prices and stock levels in this repository are demonstration samples, not the shop's real range or prices.

## Project structure

| Folder | Contents | Status |
|---|---|---|
| `docs/` | Phase plans and notes | Phase 0 plan, Phase 1 notes |
| `frontend/` | Public website (React + Vite + Tailwind) | Phase 1 done: homepage |
| `admin/` | Admin dashboard (React) | Phase 5 |
| `backend/` | REST API (Spring Boot + MySQL) | Phase 4 |

## Run the website

```powershell
cd frontend
npm install
npm run dev
```

Open http://localhost:5173.
